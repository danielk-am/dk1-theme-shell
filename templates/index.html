Questions, answered

Is the Site Editor really the editor?

Yes. Every surface on this site, from the sidebar rows to this answer, is a block you can open and change in place.

What happens to my existing content?

It graduates. Old markup carries frozen deprecations, so the editor migrates it forward without losing a word.

Do the blocks work without JavaScript?

They do. Everything renders complete before any script runs; these accordions are native disclosure, not a framework.

How does the assistant fit in?

It rides the shell. Ask the assistant opens the panel on any page, and the history action swaps it to the conversations screen.
